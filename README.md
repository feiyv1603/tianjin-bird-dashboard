**天津市观鸟数据统计仪表盘**

基于 ECharts 开发的交互式数据可视化网页。观鸟数据来自地球资源数据云的中国观鸟数据集（1980-2024），整理自中国观鸟记录中心的鸟类观察数据。天津市各区县GeoJSON数据下载自阿里云 DataV GeoAtlas。

选择被目击数量前20名鸟类，旨在直观呈现天津市各区县的观鸟记录情况。

采用三栏布局：左侧展示鸟类档案；中间为可缩放交互的天津市区县分布地图，支持鼠标拖拽与放大；右侧是鸟类各区县数量排名柱状图与时间变化趋势折线图。支持鸟类与年份的双向联动筛选。

帮助用户从宏观到微观探索天津鸟类生态的时空分布特征，具有一定的实用与科普价值。
